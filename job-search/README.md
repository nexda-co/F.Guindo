## Before Applying — Indiana State License Required

All Indiana-based pharmacy technicians (including remote workers) must hold an **Indiana Board of Pharmacy license**.

| Requirement | Detail |
|---|---|
| Age | 18+ |
| Education | High school diploma or GED |
| Certification | PTCB or ExCPT exam OR Indiana-approved training program |
| Background Check | Required |
| Application Fee | $25 |
| Licensing Body | Indiana Board of Pharmacy |

**Resources:**
- [Indiana Pharmacy Tech License Guide 2026](https://pharmacytechscholar.com/indiana-pharmacy-technician-license/)
- [Indiana Pharmacy Tech Requirements](https://pharmacytechacademy.com/indiana-pharmacy-tech-requirements)
